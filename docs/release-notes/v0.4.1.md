# v0.4.1

## Fixed

- Connection failure tracking — `on_connection_failed()` now records ALL failures
  in `auto_connect_failures`, not just manual. Auto-connect skips failed SSIDs
  instead of retrying forever.
- Stale `_manual_connecting` flag — added `_connect_attempt_id` counter so
  idle handlers that fire after `cancel_manual_connect()` won't re-set the flag.
- Auto-connect no longer blocked by manual flag — `try_auto_connect_all()` no
  longer returns early when `_manual_connecting` is true.
- Saved connection password update — delete old connection first, then
  `add_and_activate` with a fresh `SimpleConnection`. Avoids corrupting cached
  `RemoteConnection` settings.

## Changed

- `rebuild_items()` wraps property notifications in `freeze_notify()` /
  `thaw_notify()` — reduces render passes from 4→2 per rebuild.
- Dialog close_request always calls `cancel_manual_connect()` unconditionally.

## Infrastructure

- Added GitHub Actions release workflow — tag push (`v*`) builds release
  binary and creates a GitHub release.
